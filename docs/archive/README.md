# Archive — pre-pivot hardware kit designs

Everything in this folder predates the 2026-11 Android pivot: the original
12V DIY build (build-guide, build-sheet, wiring diagram), the KISS
three-module build (Pelican terminal + Jackery plant + Starlink uplink,
nested Faraday-bag EMP doctrine), buy lists, and illustration/prompt assets.

Kept because parts return at Milestone 4 (physical kit: case, owned power,
EMP bags) and because the doctrine sections (Family Test, operating modes,
offline-first rationale) still apply to the phone-centered design.

Do not treat prices, SKUs, or the mini-PC architecture here as current.
Current source of truth: ../build-sheet.md.
