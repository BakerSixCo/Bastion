# SAMPLE DOCUMENT — bundled demo data

This file ships inside the Outpost Zero app as clearly labeled sample content so the
library, search, and reader can be demonstrated before you import your own
documents. It is not field reference material.

## Unique test marker

The Outpost Zero offline test phrase is JUNIPER-7-ACTUAL. Searching for that phrase
after a fresh app start, with networking disabled, demonstrates that retrieval
runs locally: this string exists nowhere else.

## Example reference content (generic)

Water: bring clear water to a rolling boil for 1 minute to disinfect it; at
elevations above 6,500 ft (2,000 m), boil for 3 minutes. Cloudy water should be
filtered before boiling.

Signal mirror: aim using the V between two fingers, sweep the horizon slowly.
Three of anything — whistle blasts, fires, flashes — is a recognized distress
pattern.

Hypothermia: shivering, slurred speech, and clumsiness are early signs. Replace
wet clothing, insulate from the ground, add dry layers, and give warm sweet
drinks only if the person is fully alert.
